# 🎬 Netflix Frontend Clone

A Netflix-inspired landing page developed using **HTML5 and CSS3** for frontend development practice and portfolio purposes.

## 📌 About the Project

This project recreates the layout of a streaming platform homepage, featuring a dark interface, navigation bar, hero banner, promotional sections, frequently asked questions, and footer.

## ✨ Features

- Netflix-inspired dark UI
- Navigation bar with logo and buttons
- Hero banner with email input
- Get Started call-to-action
- Watch on TV section
- Offline downloads section
- Watch Everywhere section
- Kids profile section
- Frequently Asked Questions layout
- Footer with grouped links
- CSS hover effects
- Responsive styling for smaller screens

Make sure the image assets referenced by your HTML and CSS exist in `assets/images/`. Update the paths if your files use different names.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Check that all required image assets are present.
4. Open `index.html` in a web browser.
5. Alternatively, run it using the Live Server extension in VS Code.

An internet connection may be required for externally hosted images, videos, and fonts.

## ⚠️ Current Limitations

This is a frontend-only project. The sign-in button, language selection, email form, and FAQ items are not connected to complete interactive or backend functionality. Authentication and video streaming are not implemented.
